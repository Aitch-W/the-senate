# The Senate · 元老院消费决策议会（演示版）

一个本地运行的交互演示：把一件让你犹豫的商品交给 3 / 5 / 7 位「先贤」，经过逐条质询、独立表态与最终裁决，帮助你分辨「想要」与「需要」。投票仅供参考，最终决定权始终在用户手里。

## 运行

需要 Node.js 20+，无第三方依赖。

```bash
cd the-senate
npm start          # 或 node server.mjs 4180
```

然后打开 <http://127.0.0.1:4180>。Windows 也可以直接双击 `start-demo.cmd`。
换端口：`node server.mjs 4181`（同时访问 `http://127.0.0.1:4181`）。

跑一遍服务端规则测试：

```bash
node test/engine.test.mjs
```

## 首页三屏

首页是一台竖向翻页器，共三屏：

1. **The Senate**：首屏。拉丁文标题与主标题逐字浮现，副标题、提示和按钮依次升起；「进入元老院」直接翻到第三屏门廊，「向下探索」进入第二屏。
2. **一场议会，四步深思**：五个横向页面——召集、质询、表态、裁决、七贤。每页左侧是配图，右侧是说明、要点和「下一步」；顶部 01–05 标签、底部箭头 / 圆点、左右拖动、方向键都能切换。
3. **门廊 / 三处入口**：三枚手绘徽记——召集元老院、账单、个人主页；点击徽记或下方名称进入。`#forum` 仍可直接打开这一屏。

首屏油画由三层画面驱动：建筑、人物与前景桌沿按不同景深随鼠标做轻微视差；开启「减少动态效果」或关闭「动效」时回退为静态油画。

翻页方式：鼠标滚轮/触控板上下滚动一次翻一屏，触屏上下滑，或使用 `↑` / `↓`、`PageUp` / `PageDown`、右侧 I / II / III 圆点。翻页动画期间会短暂锁定，避免一次滚动连翻多屏。

## 门廊与个人主页

第三屏门廊同时保留 `#forum` 直达地址，门廊包含：

- **召集元老院**：打开提案表单，开始一场新的议会。
- **账单**：进入记账与历史（`#ledger`）。
- **个人主页**：进入 `#profile`，可设置称呼与一句话，查看议会次数、没有花出去的金额、当前可用闲钱和最近的议会记录。身份与偏好保存在当前浏览器。

门廊使用三枚手绘徽记分别代表议事厅、账本与公民身份；点击对应徽记或下方名称进入。页脚保留「继续上一场」入口，方便回到未结束的议会。

## 开发者模式（DeepSeek）

进入「个人主页」→ 页尾「DEVELOPER MODE」，开启后填写 DeepSeek API Key：

- 默认模型 `deepseek-chat`，也可以切换 `deepseek-reasoner`；Base URL 默认 `https://api.deepseek.com`。
- 点「测试连接」会调用 `/models` 验证 Key；状态会显示成功或错误。
- 开启后，新议会的**先贤质询**与**先贤表态**由 DeepSeek 生成；好友仍由真人提问、投票。
- 请求失败、Key 无效或网络中断时，会场会自动回退本地规则，并在会场底部显示「DeepSeek 未连接 · 本地回退」，不会卡住流程。
- Key 只保存在当前浏览器的 `localStorage`，不会写入会场或账本；只在测试 / 开启质询 / 表决时发送给当前部署的服务，由它转发 DeepSeek。

后端实现：`deepseek.mjs`（JSON 模式、超时、错误脱敏、结构校验），`server.mjs` 的 `/api/dev/test` 与 `start` / `deliberate` 路由；引擎接受生成结果并保留本地兜底。

## 线上部署（Cloudflare Worker + D1）

线上子域已部署：

- **Senate**：<https://senate.aitchwcx.me/>
- **个人站**：<https://aitchwcx.me/>
- 旧地址 `https://senate-chenxi-meadow.pages.dev/` 也已部署一个 302 重定向项目，会跳到 `senate.aitchwcx.me`。

实现方式不是纯静态 Pages，而是 Cloudflare Worker + Static Assets + D1：

- `worker.mjs`：同一套 `engine.mjs` / `deepseek.mjs`，负责 `/api/*`；其余请求交给 `env.ASSETS`（`public/` 静态资源）。
- `wrangler.toml`：Worker、静态资源、D1 `senate-council-rooms`、自定义域 `senate.aitchwcx.me`。
- `schema.sql`：`rooms` 表；Worker 每次变更写入 D1，好友轮询和主持人刷新都能拿到最新状态。每日 04:17 自动清理 24 小时前的会场。
- 重新部署：

```bash
cd the-senate
npx wrangler d1 execute senate-council-rooms --remote --file schema.sql
npx wrangler deploy
```

线上运行时，DeepSeek Key 仍然只由当前浏览器持有；Worker 只在测试 / 质询 / 表决请求中接收并转发它，不写入 D1。

个人站的 `personal-site/dist/index.html` 已在 `.senate-card` 上固定：

```html
data-senate-url="https://senate.aitchwcx.me/"
```

作品卡带首页截图预览；桌面悬停浮现项目介绍、技术标签和 `senate.aitchwcx.me`，点击进入子站。个人站部署在 `chenxi-meadow` Pages 项目（`aitchwcx.me` / `chenxi-meadow.pages.dev`）。

本地仍可用 `node server.mjs` 运行；也可以用 [Dockerfile](Dockerfile) 部署到任何 Node 20+ 主机。


## 议会规模与角色包

- 在提案表单里先选角色包，再选议会规模：3 人 · 快速合议庭 / 5 人 · 常规议事会（默认）/ 7 人 · 完整元老院。
- 每次从所选角色包的 7 位先贤中随机抽取对应数量，不重复；席位预览始终是一位居中、两侧成对镜像，3 / 5 / 7 席都不会出现左右偏移。
- 两套可选角色包：古罗马元老院包、华夏诸子先贤包；近现代思辨包、趣味名士彩蛋包暂为「待解锁」占位。
- 切换角色包会切换环形议事厅装饰主题和人物头像 / MBTI 标签；选择结果会随议会记录保存，回放时按原角色包还原人物与样式。

## 揭票与动效

- 质询保持串行：一次只显示一位的问题，文字逐字浮现；提交后本条锁定，再进入下一位。
- 好友席不预载问题：必须等好友通过邀请链接写下自己的质询，主持人才能回答；全部质询结束后才进入表决。
- 表决完成后，先贤观点按席位逐张翻开，文字以打字机效果出现；少数派观点会高亮，全部选票揭晓后才出现最终决定按钮。
- 页眉右上角的「动效」开关会同时关闭动画与音效，并保存到 `localStorage`；关闭后所有环节静态呈现。

## 演示流程

1. **召集**：选择角色包与人数，填写商品、价格、可用闲钱与购买理由；抽中的先贤默认入席，也可以在议事厅把任意席位换成好友。
2. **质询**：依次回答所选人数的质询，回答会封存在当前会场；好友席先等好友提问，问题逐字呈现后再回答。
3. **表态**：先贤按本地规则给出「买 / 暂缓 / 不买」；含好友席时，好友通过独立链接查看完整问答并提交自己的观点，全员提交后一起揭晓。
4. **裁决**：用户自己决定买、暂缓（冻结 3/7 天预算）或不买；决定与完整问答写入浏览器本地账本。

## 结构

- `server.mjs`：零依赖 HTTP 服务，提供静态页面与 JSON API（本地运行）。
- `worker.mjs`：Cloudflare Worker 入口，复用引擎与 DeepSeek 适配器，静态资源走 `ASSETS`，会场状态存 D1。
- `wrangler.toml` / `schema.sql`：Worker、静态资源、D1 与 `senate.aitchwcx.me` 自定义域配置。
- `engine.mjs`：会场状态机（召集 → 质询 → 封存/等待好友 → 裁决）与演示用的本地表态规则；可接收 DeepSeek 生成的质询与表态。
- `deepseek.mjs`：DeepSeek 适配器（提示词、JSON 校验、超时与错误脱敏）。
- `public/`：单页前端（`app.js`、`style.css`、`forum.css`、`council.js`、`seat-layout.js`、`hero-live.js`、`assets/shots/` 真实页面截图与七贤配图、`assets/hub-emblems.png` 门廊三徽记、`assets/ledger-desk.svg` 账单书桌主视觉、`assets/assembly-bg.svg` 舞台纹样背景）。
- `senate-references/`：设计参考与早期截图脚本，不参与运行。

## 数据与限制

- 会场保存在服务端内存中，服务重启后失效；账本、个人主页与动效偏好保存在当前浏览器的 `localStorage`。
- 先贤观点由本地规则模拟，不调用外部大模型；这是刻意保留的演示模式。
- 好友邀请链接包含一次性席位令牌，提交后不可修改；全部席位提交前，主持人也看不到封存的观点。
